# bd-practices

¡Holaaa! Este repositorio centraliza las prácticas, proyectos y entregas correspondientes a la unidad de aprendizaje de **Bases de Datos** impartida en la **Escuela Superior de Cómputo (ESCOM - IPN)**.  

El proyecto está desarrollado utilizando un flujo de control de versiones mediante ramas para cada entrega y entornos aislados con contenedores.  

## Índice de Prácticas

Cada práctica vive de forma independiente en su propia rama:

| Práctica / Proyecto | Descripción | Rama |
| :--- | :--- | :--- |
| **Práctica 1** | Modelo Entidad-Relación (notación de Chen), configuración inicial del entorno, y despliegue de contenedores. | [`practica1`](https://github.com/M4VVii/bd-chambitas/tree/practica1) |
| **Práctica 2** | Modelo EER extendido, ingeniería inversa del caso de Sismos y gestión de Issues.(INCOMPLETO) | [`practica2`](https://github.com/M4VVii/bd-chambitas/tree/practica2) |
| **Práctica 3** | *(En desarrollo)* | [`practica3`](https://github.com/M4VVii/bd-chambitas/tree/practica3) |

## Stack Tecnológico
* **Base de Datos:** PostgreSQL
* **Gestor / Cliente:** DBeaver
* **Contenedorización:** Docker & Docker Compose
* **Control de Versiones:** Git / GitHub
* **Entorno de Desarrollo:** Linux Mint
